Submitting to the Leaderboard

How to report your model's performance on KernelBench

⚠️ Self-Reported Results

Unfortunately, we don't currently have the bandwidth to manually verify submissions or coordinate with organizations. Instead, we ask that you run our evaluation script yourself and report your numbers.

To ensure fair and reproducible comparisons across the leaderboard, all submissions should use our standardized evaluation pipeline. This means running the same evaluation script, on the same hardware configuration, with the same prompting setup.

Evaluation Steps
  • Generate kernel outputs using your model with 1-shot prompting (minimum example)
  • Use Pass@1 sampling (single generation per problem)
  • Run evaluation on NVIDIA H100 GPU using our Modal eval script
  • Report the resulting metrics (GeoMean, fast_p values, correctness)
🚨 Please Be Extra Careful
  • Double-check your numbers before submitting — errors are difficult to correct after publication
  • Use the exact evaluation setup described above for fair comparison
  • Don't cherry-pick results — report the actual Pass@1 performance, not best-of-N
  • Verify correctness checking is working properly — incorrect kernels should not be counted as correct
  • Be transparent about any deviations from the standard evaluation setup

Since we rely on self-reported results, the integrity of the leaderboard depends on the community's honesty and diligence. We trust that submitters will report accurate numbers in good faith.

To submit your results, please open a pull request to the KernelBench-Leaderboard repository with your model's evaluation data. See the repository README for the expected data format.

For questions or issues, please open a GitHub issue.
