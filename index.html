Can LLMs Write
Efficient GPU Kernels?

KernelBench is a benchmark for evaluating the ability of large language models to generate efficient GPU kernels. It consists of 250 carefully curated problems across 3 difficulty levels.

📊 View Leaderboard 📄 Read Paper 💻 GitHub

The Task

Transpile PyTorch operators to optimized CUDA kernels

KernelBench structures the problem for LLMs to transpile operators described in PyTorch to CUDA kernels, at whatever level of granularity they desire.

Each problem provides a reference PyTorch implementation that the model must convert into an efficient CUDA kernel. The generated kernel is then evaluated for both correctness (does it produce the same output?) and performance (is it faster than the baseline?).

This benchmark tests whether LLMs can understand and optimize the low-level computational patterns that power modern deep learning, from simple matrix multiplications to full model architectures like transformers and diffusion models.

Difficulty Levels

250 problems across 3 levels of increasing complexity

🧱 Level 1 100 problems

Single-kernel operators: the foundational building blocks of neural nets — convolutions, matrix multiplies, layer normalization, and more.

🔗 Level 2 100 problems

Simple fusion patterns where a fused kernel would be faster than separated kernels — Conv + Bias + ReLU, Matmul + Scale + Sigmoid.

⚛️ Level 3 50 problems

Full model architectures requiring end-to-end optimization — MobileNet, VGG, ResNet, MiniGPT, Mamba, and Vision Transformers.
